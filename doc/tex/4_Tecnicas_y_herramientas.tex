\capitulo{4}{Técnicas y herramientas}

Este capítulo presenta las principales técnicas y herramientas mencionadas en la memoria y en los anexos.

\section{Técnicas}

\subsection{Gestión y control del trabajo}

\begin{itemize}
	\item \textbf{Metodologías ágiles.} Enfoques de gestión basados en desarrollo iterativo, entrega incremental y adaptación continua a los cambios.
	
	\item \textbf{Scrum.} Marco de trabajo ágil organizado en iteraciones llamadas \textit{sprints}. Cada \textit{sprint} parte de una lista priorizada de trabajo, denominada \textit{Product Backlog}, y finaliza con un incremento revisable del producto.
	
	\item \textbf{Control de versiones.} Técnica que registra la evolución de un conjunto de archivos y permite recuperar estados anteriores.
\end{itemize}

\subsection{Diseño y arquitectura del software}

\begin{itemize}
	\item \textbf{Arquitectura modular.} Técnica que divide una aplicación en componentes con responsabilidades diferenciadas, reduciendo el acoplamiento entre partes del sistema.
	
	\item \textbf{Separación de responsabilidades.} Principio de diseño que asigna cada función del sistema a una capa concreta, evitando concentrar toda la lógica en un único módulo.
	
	\item \textbf{Modelo-Vista-Controlador.} Patrón arquitectónico que separa una aplicación en tres partes principales: modelo, vista y controlador. Esta separación facilita organizar la lógica de datos, la presentación y la gestión de peticiones.
	
	\item \textbf{Modelo.} Parte encargada de representar la información y las reglas asociadas a los datos. En una aplicación con persistencia, suele estar relacionado con las entidades, relaciones y operaciones sobre la base de datos.
	
	\item \textbf{Vista.} Parte responsable de presentar la información al usuario. En aplicaciones \textit{web}, suele materializarse mediante plantillas HTML, hojas de estilo y contenido generado para el navegador.
	
	\item \textbf{Controlador.} Parte encargada de recibir las peticiones del usuario, coordinar la lógica necesaria y devolver una respuesta. Actúa como intermediario entre la vista, el modelo y otros servicios de la aplicación.
	
	\item \textbf{Patrón factoría.} Patrón creacional que centraliza la creación o selección de objetos, delegando en un componente especializado la decisión de qué implementación utilizar \cite{gamma1994design}.
	
	\item \textbf{Modelo relacional.} Modelo de datos basado en tablas, filas, columnas, claves primarias, claves ajenas y restricciones de integridad.
	
	\item \textbf{Mapeo objeto-relacional.} Técnica que relaciona tablas de una base de datos con clases del lenguaje de programación, permitiendo trabajar con entidades en lugar de sentencias SQL directas.
\end{itemize}

\subsection{Desarrollo web y seguridad}

\begin{itemize}
	\item \textbf{Arquitectura cliente-servidor.} Modelo en el que un cliente realiza peticiones y un servidor las procesa, ejecuta la lógica correspondiente y devuelve una respuesta.
	
	\item \textbf{\textit{Tokens} JWT.} Mecanismo que representa información firmada sobre una identidad o sesión, permitiendo validar peticiones protegidas \cite{jwt_docs}.
	
\end{itemize}

\subsection{Visión por computador e inteligencia artificial}

\begin{itemize}
	\item \textbf{Detección de objetos.} Localiza entidades dentro de una imagen y les asigna una clase.
	
	\item \textbf{Estimación de puntos clave.} Localiza puntos relevantes de una estructura.
	
	\item \textbf{Segmentación de imágenes.} Divide una imagen en regiones o clases a nivel de píxel.
	
	\item \textbf{Clasificación de imágenes.} Asigna una o varias etiquetas a una imagen completa o a una región concreta.
\end{itemize}

\subsection{Pruebas, calidad y despliegue}

\begin{itemize}
	\item \textbf{Pruebas unitarias.} Verifican componentes concretos de forma aislada.
	
	\item \textbf{\textit{Mocking}.} Sustituye temporalmente una dependencia por una respuesta controlada, permitiendo aislar pruebas o simular errores.
	
	\item \textbf{Cobertura de código.} Métrica que indica qué partes del código han sido ejecutadas durante las pruebas.
	
	\item \textbf{Análisis estático.} Revisión del código fuente sin ejecutarlo para detectar problemas de mantenibilidad, duplicación, complejidad, seguridad o estilo.
	
	\item \textbf{Contenerización.} Técnica que empaqueta una aplicación junto con sus dependencias en una unidad reproducible.
\end{itemize}

\section{Herramientas}

\subsection{Gestión, lenguaje y entorno}

\begin{itemize}
	\item \textbf{Jira.} Herramienta de gestión de proyectos \cite{jira_docs}.
	
	\item \textbf{Git.} Sistema de control de versiones \cite{git_docs}.
	
	\item \textbf{GitHub.} Plataforma de alojamiento de repositorios Git \cite{github_docs}.
	
	\item \textbf{Python.} Lenguaje de programación multiplataforma y multiparadigma, con un amplio ecosistema de bibliotecas para desarrollo \textit{web}, procesamiento de datos, pruebas e inteligencia artificial \cite{python_docs}.
	
	\item \textbf{Linux.} Familia de sistemas operativos libres.
	
	\item \textbf{Debian.} Distribución GNU/Linux caracterizada por su estabilidad \cite{debian_docs}.
	
	\item \textbf{Visual Studio Code.} Editor de código. \cite{vscode_docs}.
	
	\item \textbf{DBeaver.} Herramienta gráfica de administración de bases de datos que permite inspeccionar esquemas, consultar tablas y ejecutar sentencias SQL \cite{dbeaver_docs}.
\end{itemize}

\subsection{Visión por computador e inteligencia artificial}

\begin{itemize}
	\item \textbf{YOLO.} Familia de modelos de detección de objetos cuyo nombre procede de \textit{You Only Look Once}. Su propuesta original fue presentada por Redmon, Divvala, Girshick y Farhadi, y plantea la detección como un único problema de regresión en el que una red predice cajas delimitadoras y probabilidades de clase en una sola pasada \cite{redmon2016yolo}.
	\textbf{YOLOv8.} Versión de la familia YOLO desarrollada por Ultralytics. Soporta tareas de visión por computador como detección de objetos, segmentación de instancias, clasificación de imágenes, estimación de pose y detección con cajas orientadas \cite{ultralytics_yolov8,ultralytics_tasks}.
	
	\item \textbf{Ultralytics.} Biblioteca de Python asociada a modelos YOLO modernos. Proporciona una interfaz para predicción, entrenamiento, validación, exportación y uso de modelos preentrenados \cite{ultralytics_yolov8}.
	
	\item \textbf{MediaPipe.} \textit{Framework} desarrollado por Google para construir soluciones de percepción mediante aprendizaje automático. Incluye tareas de visión como detección de manos, estimación de pose, análisis facial, segmentación, detección de objetos y reconocimiento de gestos \cite{lugaresi2019mediapipe,google_mediapipe_docs}.
	
	\item \textbf{MediaPipe Tasks.} Interfaz de alto nivel de MediaPipe orientada a ejecutar tareas predefinidas de visión, audio y texto. En visión por computador incluye tareas como \textit{Hand Landmarker}, \textit{Pose Landmarker}, \textit{Face Landmarker}, \textit{Object Detector}, \textit{Image Segmenter} y \textit{Gesture Recognizer} \cite{google_mediapipe_docs}.
	
	\item \textbf{\textit{Hand Landmarker}.} Tarea de MediaPipe destinada a detectar puntos clave de las manos. Devuelve coordenadas de puntos de la mano, coordenadas del mundo y lateralidad de la mano detectada \cite{mediapipe_hand_landmarker}.
	
	\item \textbf{\textit{Pose Landmarker}.} Tarea de MediaPipe destinada a detectar puntos clave del cuerpo humano en imágenes o vídeo. Devuelve puntos de pose en coordenadas de imagen y coordenadas tridimensionales del mundo \cite{mediapipe_pose_landmarker}.
	
	\item \textbf{OpenCV.} Biblioteca de visión por computador y procesamiento de imágenes. Incluye funciones para lectura, escritura, transformación, filtrado y dibujo sobre imágenes \cite{opencv_docs}.
	
	\item \textbf{NumPy.} Biblioteca de Python para cálculo numérico basada en arreglos multidimensionales y operaciones matriciales eficientes \cite{numpy_docs}.
\end{itemize}

\subsection{Desarrollo web, persistencia y configuración}

\begin{itemize}
	\item \textbf{Flask.} \textit{Framework} de desarrollo \textit{web} para Python. Permite definir rutas, procesar peticiones HTTP, devolver respuestas y estructurar aplicaciones mediante extensiones.
	También permite organizar rutas y vistas mediante \textit{Blueprints}, un mecanismo de modularización propio de Flask. \cite{flask_docs}.
	
	\item \textbf{Jinja.} Motor de plantillas utilizado por Flask para generar HTML dinámico a partir de plantillas y datos del servidor \cite{flask_docs}.
	
	\item \textbf{HTML.} Lenguaje de marcado para páginas \textit{web} \cite{mdn_html}.
	
	\item \textbf{CSS.} Lenguaje de estilos para la presentación visual de HTML \cite{mdn_css}.
	
	\item \textbf{JavaScript.} Lenguaje de programación ejecutado principalmente en el navegador, utilizado para añadir interacción y comunicación con servicios \textit{web} \cite{mdn_javascript}.
	
	\item \textbf{Flask-JWT-Extended.} Extensión de Flask para crear, verificar y proteger rutas mediante \textit{tokens} JWT \cite{jwt_docs}.
	
	\item \textbf{Werkzeug.} Biblioteca usada por Flask. Incluye utilidades para peticiones, respuestas, seguridad, nombres de ficheros y contraseñas \cite{werkzeug_docs}.
	
	\item \textbf{python-dotenv.} Biblioteca que permite cargar variables de entorno desde ficheros \texttt{.env} \cite{dotenv_docs}.
	
	\item \textbf{MariaDB.} Sistema gestor de bases de datos relacional, derivado de MySQL \cite{mariadb_docs}.
	
	\item \textbf{SQLAlchemy.} Biblioteca de Python para acceso a bases de datos y mapeo objeto-relacional. Permite definir modelos, relaciones y consultas desde el código \cite{sqlalchemy_docs}.
	
	\item \textbf{Flask-SQLAlchemy.} Extensión que integra SQLAlchemy con Flask, simplifica la configuración de modelos y sesiones de base de datos \cite{sqlalchemy_docs}.
	
	\item \textbf{SQLite.} Sistema gestor de bases de datos relacional ligero, embebido y basado en ficheros \cite{sqlite_docs}.
	
	\item \textbf{JSON.} Formato ligero de intercambio de datos basado en texto \cite{json_docs}.
\end{itemize}

\subsection{Pruebas, calidad, despliegue y documentación}

\begin{itemize}
	\item \textbf{Pytest.} \textit{Framework} de pruebas para Python. Permite definir pruebas unitarias, utilizar \textit{fixtures}, parametrizar casos y generar informes. \cite{pytest_docs}.
	
	\item \textbf{unittest.mock.} Módulo de Python para crear objetos simulados y reemplazar dependencias durante una prueba \cite{python_unittest_mock_docs}.
	
	\item \textbf{GitHub Actions.} Plataforma de automatización de GitHub para definir flujos de integración continua, pruebas, análisis y despliegues \cite{githubactions}.
	
	\item \textbf{SonarCloud.} Servicio de análisis estático de código orientado a detectar problemas de mantenibilidad, duplicación, seguridad, complejidad y calidad general \cite{sonarcloud}.
	
	\item \textbf{Docker.} Plataforma para crear y ejecutar contenedores que empaquetan una aplicación con sus dependencias \cite{docker}. 
	\textbf{Docker Compose.} Herramienta para definir y ejecutar aplicaciones formadas por varios contenedores relacionados mediante un archivo de configuración \cite{dockercompose}.
	
	\item \textbf{Kubernetes.} Plataforma de código abierto para la orquestación de contenedores. Permite automatizar el despliegue, escalado y gestión de aplicaciones contenedorizadas en entornos distribuidos \cite{kubernetes_docs}.
	
	\item \textbf{dbdiagram.io.} Herramienta \textit{web} para diseñar y representar modelos relacionales mediante una sintaxis textual \cite{dbdiagram_docs}.
	
	\item \textbf{Draw.io.} Herramienta para crear diagramas \cite{drawio_docs}.
	
	\item \textbf{LaTeX.} Sistema de composición tipográfica utilizado en documentación científica y académica \cite{wiki:latex}.
	
	\item \textbf{ChatGPT y Gemini.} Herramientas de inteligencia artificial generativa orientadas a la generación, revisión y transformación de documentación, código, pruebas, explicaciones e imágenes \cite{google_gemini, openai_chatgpt}.
	
\end{itemize}
