\capitulo{2}{Objetivos del proyecto}

El presente Trabajo de Fin de Grado tiene como finalidad el desarrollo de una aplicación web orientada al procesamiento de imágenes mediante modelos de inteligencia artificial. La aplicación deberá permitir enviar una imagen al servidor, ejecutar sobre ella un modelo de análisis y devolver un resultado útil tanto desde el punto de vista funcional como visual.

A partir de esta finalidad general, pueden distinguirse dos tipos de objetivos: por un lado, los objetivos relacionados con el software que se desea construir y, por otro, los objetivos técnicos necesarios para llevar a cabo su diseño e implementación.

\section{Objetivo general}

El objetivo general del proyecto es desarrollar una aplicación web capaz de ejecutar distintos modelos de inteligencia artificial sobre imágenes, devolviendo como resultado información estructurada y una imagen procesada.

\section{Objetivos del software}

Los principales objetivos del software a desarrollar son los siguientes:

\begin{itemize}
	\item Permitir la carga de imágenes por parte del usuario para su procesamiento.
	\item Integrar distintos modelos de inteligencia artificial dentro de una misma aplicación.
	\item Ofrecer resultados comprensibles, tanto en formato estructurado como visual.
	\item Diferenciar la interfaz web de uso interactivo de la API destinada a pruebas o integración.
	\item Diseñar una base funcional que pueda ampliarse en el futuro con nuevos modelos, modos de ejecución y otras funcionalidades.
\end{itemize}

\section{Objetivos técnicos}

Junto a los objetivos funcionales, el proyecto plantea varios objetivos técnicos:

\begin{itemize}
	\item Diseñar una arquitectura modular que facilite la organización y evolución del sistema.
	\item Emplear tecnologías adecuadas para el desarrollo de aplicaciones web con procesamiento de imágenes e inteligencia artificial.
	\item Definir un modelo de datos que permita incorporar persistencia y soporte para futuras ampliaciones.
	\item Implementar una base técnica mantenible y coherente con un posible despliegue real.
\end{itemize}

En conjunto, el proyecto busca no sólo construir una aplicación funcional, sino también establecer una base técnica sólida sobre la que pueda apoyarse su evolución posterior.
