## Base de datos

Los scripts de base de datos se encuentran en:

/db/schema.sql
/db/scritp_db.sql
/db/data.sql

El archivo `schema.sql` permite la recreación completa del esquema de la base de datos, incluyendo la definición de tablas, claves primarias, claves foráneas y restricciones de integridad.

El archivo `scritp_db.sql` crea todas las tablas en la base de datos ya creada si está sin vacía.

El archivo `data.sql` incluye un conjunto de datos iniciales que permiten poblar la base de datos con información de prueba, facilitando la validación y demostración del sistema.
